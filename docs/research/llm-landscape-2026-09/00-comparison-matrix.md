# LLM landscape 2026-09 — comparison matrix (as of 2026-09-24)

Synthesis of the 25 research docs in this folder for one target: a **subscription-first, headless, single-tenant assistant server** (Mac Mini M4 16 GB, Python 3.12, Claude Agent SDK on Claude Max, Postgres/Redis, Telegram + web dashboard, launchd) with a **paper-trading finance lab** (Atlas). Every number below is taken from a doc in this folder and cited by doc path (`§` = section of that doc); nothing new was fetched. Where docs disagree, §5 says which one to believe.

Reading rules that apply to every table:
- **Cost tables use the set's synthetic job (150k input + 15k output tokens, 0 % cache)** unless marked. The only measured job shape on this server — median ~98.5k input at **81.7 % cache-read**, ~1.9k output, ~30–60 scheduled jobs/month (`crosscut-finance-trading-ai.md §3` "Empirical calibration", read from `volumes/audit_log`) — makes every metered figure 5–8× cheaper and makes the 1,000-job column irrelevant to this box today.
- **Benchmark numbers are Artificial Analysis Intelligence Index v4.3.2 only** (`crosscut-benchmarks-reviews.md §5`); pre-rescale figures (Gemini 3.8 Flash "59", Muse Spark "61–62", Nemotron Ultra "48", Qwen3.8-27B "52") are not comparable and are not used.
- **Fit scores** are 1–10 on five axes (Research / Coding-agentic / Cost / Automation / Trading research). Each vendor doc self-scored with its own anchors; `crosscut-benchmarks-reviews.md §7` declares its reconciled table authoritative for the router. Both are shown.

## 1. Executive summary (one screen)

1. **Claude Max + Claude Code/Agent SDK stays the primary executor.** Opus 5.5 leads the independent composite (AA v4.3.2 = 58; Fable 5.1 and GPT-6 Astra tie at 53) and Claude Code has the most complete headless contract (stream-json events, `--json-schema`, resume, budget caps, OTEL). Single-owner use of the unmodified binary on your own Max plan is the explicitly permitted path — but policy has reversed four times in 2026, `--bare` (announced future `-p` default) ignores subscription OAuth, and `ANTHROPIC_API_KEY` in env silently flips billing. Pin the CLI, mint a one-year `claude setup-token`, never pass `--bare`, and turn "Help improve Claude" **off** (30-day retention instead of 5 years). (`claude-anthropic.md §3, §7, §8`; `crosscut-subscription-automation-tos.md §3.1, §7`)
2. **Second opinion = Codex on the ChatGPT plan (Gray/Yes\*), GPT-6 Sol/Astra.** Terminal-Bench 4.0 is a statistical tie at the top (Astra+Codex 58.2 % vs Fable 5.1+Claude Code 57.9 %) at half the run cost; Codex is the *only* subscription lane that exposes remaining 5-h/weekly budget to a script (`account/rateLimits/read`). Plan auth for owner-only jobs; `CODEX_API_KEY` for anything a second person consumes; `features.goals = false`; `otel.metrics_exporter` defaults to OpenAI's `statsig` — set `none`. (`chatgpt-openai.md §3, §7, §8`)
3. **Reviewer independence is not what the lineage argument assumed.** Anthropic's Feb/Sep 2026 disclosures name DeepSeek, Moonshot/Kimi, MiniMax and Alibaba as having distilled Claude on exactly the coding/agentic/tool-use tasks a second reviewer would check. Independence ranking for reviewing Claude output: Codex/GPT-6 ≈ Gemini > Grok > GLM/Z.ai (unnamed, unproven) > Qwen > Kimi/MiniMax/DeepSeek (named — third vote only, never the INV-13 gate). Measure pairwise overlap on the server before trusting any pair. (`crosscut-subscription-automation-tos.md §5.2a`; `crosscut-benchmarks-reviews.md §7`; `runtimes-aggregators.md §3(g)`)
4. **The cheap frontier is GLM-5.3-Flash, not Gemini 3.8 Flash.** Same AA band (42 vs 41) at one-fifth the price ($0.15/$0.50 vs $0.75/$3.75; $0.03 vs $0.17 per synthetic job; $0.25 vs $1.24 to run the whole index). DeepSeek V4.1 Flash (AA 39, 0.92 s TTFT, 232 tok/s) is the latency pick; GPT-6 Luna ($0.10/$0.50) the cheapest per task at low effort; MiMo-V2.6-Pro is the top open-weights model (AA 46) at $0.435/$0.87 with $0.0036 cached input. Gemini 3.8 Flash keeps only throughput (292 tok/s) and audio/video input. (`crosscut-benchmarks-reviews.md §5` head-to-head; `xiaomi-mimo.md §8`)
5. **Which subscriptions may be scripted:** *allowed* — Claude Max (first-party binary), Cursor (SDK/CLI draw from the pool by design), Kiro (official `KIRO_API_KEY` for paid tiers), GitHub Copilot (SDK explicitly for all subscribers), Mistral Pro credits and Ollama Cloud credits (ordinary metered use bundled in a subscription); *grey* — ChatGPT plan via Codex, Kimi Code via documented channels, MiniMax Token Plan, Z.ai Coding Plan inside "officially supported tools", SuperGrok via Grok Build; *banned in writing* — Alibaba Coding/Token Plan, Xiaomi Token Plan, Perplexity consumer, Antigravity/Gemini OAuth from any third-party tool (accounts terminated), every consumer web app driven by a script. (`crosscut-subscription-automation-tos.md §3.7`)
6. **Data handling decides where theses go, and ten lanes now clear the bar:** Claude Max with training off (30 d, no ZDR), Claude API, OpenAI API (`store=false`, ZDR-eligible), Gemini paid key, xAI API (no training, 30-day delete, self-serve ZDR), Z.ai metered API ("not saved", Singapore), Perplexity API (ZDR), Meta standard tier, Qwen on a non-China region key (conditional), local. **Never:** DeepSeek (no contractual commitment, PRC storage), Gemini unpaid / Antigravity on a Google account (trains, human review), Kimi individual keys (trains by default), MiniMax (trains, no opt-out), Z.ai Coding Plan and any "contributor" tier. Fable 5.x is 30-day-retained on every auth mode. (`crosscut-benchmarks-reviews.md §7` data-handling matrix; `crosscut-subscription-automation-tos.md §3.8`)
7. **"Watch their progress" is buildable but no vendor ships the sink.** Remaining-budget reads exist for Claude (status-line JSON `rate_limits.five_hour/seven_day`, Pro/Max, interactive session only), Codex (`account/rateLimits/read` + `updated` push), Kimi Code (`kimi web` `/api/v1/oauth/usage`) and MiniMax (`/v1/token_plan/remains`); OTLP export exists on Claude Code and Codex only. Everything else is dashboard-only. Recommended sink: one Postgres event table + JSONL mirror with a common schema, an optional OTEL collector (~100–200 MB), *no* Langfuse (needs 16 GiB) and *no* LiteLLM daemon (4 GiB/worker floor + March 2026 supply-chain compromise). (`crosscut-subscription-automation-tos.md §3.10–3.10a`; `runtimes-aggregators.md §3(c)`; `cloudflare-ai-gateway.md §8`)
8. **For the Telegram surface the knob is effort, not model.** Measured TTFT: Haiku 4.5 0.63 s, Sonnet 5 low 1.80 s / medium 2.36 s, GPT-6 Luna/Sol at `none` 0.86/1.00 s, DeepSeek V4.1 Flash 0.92 s, MiniMax M3 1.28 s, Mistral Small 4 0.77 s, Grok 4.7 0.92 s (but 40 tok/s). Unusable as a first responder: Opus 5.5 (5.2 s even at low; 21 s medium), Fable 5.1 (≥6.3 s), Gemini 3.8 Flash at high (14.7 s), Kimi K3 (3.8 s + always-on reasoning), any max-effort frontier model (108–352 s). Route the bot to Sonnet 5 low/medium and hand long work to a job with an ack. (`crosscut-benchmarks-reviews.md §5` latency table; `crosscut-subscription-automation-tos.md §5.2`)
9. **Finance: bring your own data plane; no LLM has directional edge.** Only Perplexity ships a vendor-native finance tool (`finance_search`, $5/1k calls); everything else is web search. The free MCP tier — Alpaca paper (IEX real-time websocket), `sec-edgar-mcp`, Massive Basic (EOD, 5/min), Finnhub free — plus Grok `x_search` ($5/1k posts) as the only programmatic social feed covers the lab. Population-scale 2026 evidence (3,500-vault fleets, leakage-safe evals, Alpha Arena) says LLM traders mis-size and lose; what works is tool-grounded memos, factor *proposing* behind a frozen statistical referee, nowcasting and monitoring. Every vendor AUP has an advice/reliance clause (Anthropic's consumer terms literally: "not… to buy or sell securities"), all of them satisfied by owner-only paper research with a human on the order path. (`crosscut-finance-trading-ai.md §1, §5, §6, §8`)
10. **Operational reality: churn, outages, and unpublished concurrency.** Claude Code shipped 10 releases in 10 days, Antigravity CLI 10 in 13, mcode 47 npm versions in 41 days, Codex weekly; pin every binary and smoke-test on bump. Same-window incidents (Aug 1–Sep 24, vendor pages): Anthropic 37, OpenAI 33, Mistral day-long outages in both months, xAI "0 declared" but StatusGator grade D; nobody sells a numeric SLA on a self-serve tier. No primary subscription lane (Claude, Codex, Gemini/Antigravity, Copilot, Grok Build) publishes a concurrent-session cap — fan-out is a token window, start at 2/2/1/1 and raise on clean `rate_limit` telemetry. Untrusted inputs (Telegram text, fetched pages, MCP results) reach only A-rated sandboxes: Claude Code `-p` with `failIfUnavailable` + `strictAllowlist`, and Codex `exec` (network off by default). (`crosscut-subscription-automation-tos.md §3.8a, §3.10b, §5.1, §5.3`)
