# Library — design documents

Generated index of every document under `docs/` and `.context/org/`. Each document carries YAML front-matter with a stable `id` (`<type>-<date>-<slug>`, or `<type>-<slug>` for charters and guides), a `type`, a `status` and its supersession links.

Statuses: `proposed` (written, not approved) · `accepted` (approved, not built) · `built` (code exists, not necessarily deployed) · `shipped` (deployed / in force) · `superseded` (replaced; row struck through with `→ <successor>`) · `historical` (record of a past state, not current) · `reference` (kept as a reference, no implementation status) · `living` (maintained continuously).

Use `python scripts/lib.py status <id>` to check whether a document is current, and `python scripts/lib.py show <id> --section <n|heading>` to read one section without loading the whole file. Cite a document as `lib: <id> §<heading>`.
